# 书页 · shuye-demo

> 本目录是「书页」项目的独立副本，与仓库里的 `mednexus/`、`online-demo/` **并列存放，互不覆盖**。
> 完整说明见 [README.md](README.md)。

## 快速开始

```powershell
cd shuye-demo
python server.py 7860          # 浏览器打开 http://127.0.0.1:7860
```

只需要 Python 3.10+，不需要安装任何第三方包。

**注意**：仓库里没有教材和索引（`.gitignore` 已排除），第一次运行要先按
[README.md「二、怎么跑起来」](README.md#二怎么跑起来) 生成 `book_*.jsonl` 与 `chunks.jsonl`，
否则页面能开但查不到内容。

## 与其他目录的关系

| 目录 | 内容 | 启动 |
|---|---|---|
| `mednexus/` | 医枢 MedNexus 本地版（主动诊断 + 按要点评分） | `python mednexus/server.py --open` |
| `online-demo/` | 医枢在线演示静态版 | `python -m http.server 7871 --directory online-demo/dist` |
| **`shuye-demo/`** | **书页（教材页级溯源问答）** | **`python server.py 7860`** |

两个项目默认端口都是 7860，**同时启动时要错开**：`python server.py 7861`。

## 改动约定

- 本目录是独立副本，改动**只影响本目录**，不会影响工作区里的原始版本
- 提交前先本地跑一遍：`python server.py` 看页面、`python benchmark.py` 看基准（应保持 10/10 命中、4/4 拒答）
- 教材与索引**不要提交**，`.gitignore` 已排除
