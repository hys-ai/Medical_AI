三本均有完整文字层（非扫描件），无需 OCR。

## 2. 方法

1. 纯标准库实现 PDF 解析：对象流（ObjStm）展开 → 页面树遍历 → ToUnicode CMap 解析 → 内容流文本算子提取 → Form XObject 递归
2. 按自然段切块，单块上限 320 字，块级 metadata 记录 `{教材, 印刷页码}`
3. 中文按字符二元组（bigram）+ 英文按词建倒排索引，BM25 打分
4. 输出结果强制携带 `[教材 P页码]` 引用

## 4. 打样中发现的四个真问题（可直接写进方案）

1. **印刷页码偏移不统一**：三本书分别是 +19 / +29 / +23，必须逐本标定，且前置页（封面、序、目录）没有印刷页码，需单独标记为"前置页"不参与引用。
2. **术语同义导致漏检**：学生问"限速酶"，教材写"关键酶"，纯字面检索失配。第 8 个问题即此情况。解决：建立课程级术语同义词表（限速酶↔关键酶、三羧酸循环↔柠檬酸循环/TCA）。
3. **第 10 版教材没有"学习目标"栏目**（三本书中"学习目标"出现 0 次），章末只有"思考题/小结"。因此"掌握程度"不能从教材自身获得，必须引入外部标准（见第 5 节）。
4. **检索粒度影响引用质量**：按页整页切块时，跨页知识点（如"三羧酸循环"横跨 P114–P119）会导致引用页码偏一页，需按"段落块"而非"整页"索引——本版已改为段块。

## 5. "掌握程度"的外部标准替代方案

校内大纲缺失或多年未更新，改用三级外部标准 + 显式来源标注：

| 层级 | 标准 | 性质 | 粒度 |
|---|---|---|---|
| L1 | 《医师资格考试大纲（临床类别·医学综合）》 | 国家考试标准，逐年更新 | 单元–细目–要点，含掌握/熟悉/了解 |
| L2 | 《临床医学综合能力（西医）考试大纲》（考研） | 教育部考试标准 | 科目–条目，多以掌握/熟悉/了解表述 |
| L3 | 本校课程教学日历/学时分配 | 校内口径，需向任课教师索取 | 章节–学时 |
| L4（可选） | 历年真题考点频次 | 数据驱动，需自建题库 | 知识点频次 |

规则：以 L1 为主、L2 补充、L3 校准；**冲突时取更高要求并标注分歧**（例如"执医大纲：掌握；校 2019 版考核标准：了解"）。系统展示时始终附来源，不隐藏不一致。

## 6. 结论

页级引用在现有三本教材上技术可行，检索延迟可忽略，10 个课程问题全部命中正确页码，4 个域外问题全部正确拒答；剩余误差主要来自术语同义与跨页知识点，均有明确解法。建议以"教材页级引用 + 外部考试标准掌握度 + PubMed 文献"三层锚定作为项目主线。
