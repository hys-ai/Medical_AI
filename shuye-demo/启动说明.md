# 启动说明

书页 · 教材溯源学习助手 —— 所有和“启动”有关的东西都在这个文件夹里。

---

## 最快的办法：双击

项目根目录里：

| 文件 | 双击后 |
|---|---|
| **`启动书页.bat`** | 弹出黑窗口 → 自动打开浏览器 → 窗口关掉服务就停 |
| **`run_app.ps1`** | 同上；可以右键选“使用 PowerShell 运行” |
| **`scripts\启动.bat`** | 后台静默启动，不占窗口 |
| **`scripts\停止.bat`** | 停止服务 |

桌面上还有两个图标（由 `tools\make_shortcuts.py` 生成）：

- **书页** → 后台启动并打开浏览器
- **书页（关闭服务）** → 停止服务

打开的地址都是 <http://127.0.0.1:7860>

## 这些脚本是怎么找到程序的

三层定位，任何一层成立就能跑：

1. **项目自带的 `python.exe`** —— 优先级最高。换电脑、换文件夹都不用重装 Python
2. **系统装了的 python** —— `PATH` 里能找到就直接用
3. **`py` 启动器** —— Windows 常见的另一种调用方式

三个都找不到时，黑窗口会提示去 python.org 装 3.10 以上版本。

启动脚本还会**自动识别自己所在的文件夹**，不依赖任何写死的路径，所以整个文件夹随便挪位置都能用。

## 换一台电脑

**简单做法**：把整个文件夹复制过去（要连同 `python.exe`）。双击 `启动书页.bat` 即可。

**如果 `python.exe` 丢了**：在任意一台装了 Python 的电脑上运行

```powershell
python tools\bundle_python.py
```

会把本机 Python 复制进项目目录。

> 注意：复制过去的 `python.exe` 依赖本机安装的 Python 目录，
> 只能在同一台机器（或同版本安装）上生效。
> 真正的“零依赖分发”需要便携版 Python，见下方“已知限制”。

## 常见问题

**双击后黑窗口一闪就没了**

说明脚本报错了。改用 `启动书页.bat`（窗口会停住），或者手动运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\launch_window.ps1
```

把报错截图发出来。

**浏览器显示“无法访问此网站”**

- 先看黑窗口里有没有 `Shuye is starting ...`
- 检查端口被占用：`netstat -ano | findstr :7860`
- 换端口：`python server.py 7861`，然后访问 <http://127.0.0.1:7861>

**双击 .ps1 提示“禁止运行脚本”**

用 `.bat` 入口，或者右键 `.ps1` → 使用 PowerShell 运行。
`.bat` 内部已经带 `-ExecutionPolicy Bypass`，不会受限制。

**改了代码想重启**

1. 运行 `scripts\停止.bat`（或关掉黑窗口）
2. 重新双击 `启动书页.bat`

**为什么不能直接双击 `web\index.html`**

页面本身是空壳，所有数据都来自本地服务的 `/api/ask` 接口。
直接打开 HTML 没有服务端，会白屏 —— 必须通过 `server.py` 启动。

## 已知限制

- **`python.exe` 不是便携版**：它只是把本机解释器复制过来，依赖本机 Python 安装目录。换到没装 Python 的电脑会失败。
- **真正的便携版**：需要下载 python.org 的 Windows embeddable package 解压到 `portable\python\`，启动脚本会自动优先使用它（`Find-Python` 里已经写了这条路径）。
- **`libs\` 文件夹**：旧版 gradio 界面用的依赖，新界面用不到，分发时可以整个删掉（269 MB）。
