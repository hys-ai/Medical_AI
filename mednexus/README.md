# 医枢 MedNexus

根据本次提供的两份 Word 文档、区别说明、项目记录和三张界面图片实现的本地医学主动学习智能体原型。它围绕一个知识点推进学习：进入章节后主动诊断，按要点判断缺口，提供定向补学，遇到具体开放性疑问再连接 PubMed，最后用迁移题返回同一个知识点。

## 与原「书页」项目的合并说明

2026-10-24 完成了两套原型的合并：**保留本项目的教学流程，替换它的证据层**。

| 部分 | 来源 | 说明 |
|---|---|---|
| 诊断 → 三要点评分 → EMA 掌握度 → 补学 → 迁移 → 报告 | 本项目 | 未改动 |
| 教材页级检索（`textbook.py`） | 书页 | **新增**：BM25 + IDF 覆盖率，命中即返回印刷页码 |
| 拒答门槛（覆盖率 + 至少命中 2 个词） | 书页 | **新增**，取代原先只看自编学习卡的策略 |
| PubMed 检索 / 证据分级 / 缓存 | 本项目 | 未改动 |
| 学研判断闸门 `research_gate` | 本项目 | 未改动 |

行为变化（会影响旧测试与旧文档表述）：

1. 自由提问**优先返回教材原文段落**（`kind: textbook`，带 `page`），索引未命中才回退到自编学习卡（`kind: note`，`page` 为 `null`）。
2. 因此原先“所有引用都不带页码”的断言已更新为“只有教材索引来源可带页码，学习卡不得带页码”。
3. 索引文件放在仓库根目录 `chunks.jsonl` 或 `mednexus/data/chunks.jsonl`，**不入库**；没有索引时系统仍可运行，只是没有页码可引。

## 启动

需要 Python 3.10 或更新版本，无需安装第三方 Python 包或 Node.js。

双击本目录的 `启动医枢.bat`，浏览器会打开 `http://127.0.0.1:7860`。保持启动窗口运行，按 Ctrl+C 停止服务。也可以从终端执行：

```powershell
cd mednexus
python server.py --open
```

移到其他电脑后，先安装 Python，再双击启动脚本。脚本按自身位置寻找文件，不依赖原电脑的中文绝对路径。端口占用时可运行 `python server.py 7861 --open`。请通过服务地址访问，不要直接双击 `web/index.html`。

## 已实现的使用流程

1. 总览展示真实的学习记录，推荐最需要巩固或尚未测评的知识点。初始数据全为零，不使用设计图里的虚构成绩。
2. “我的学习”提供脑神经示例章节、分组知识点、推荐任务和四种学习入口。自动评分仍覆盖 10 个知识点、20 道三要点题；完整大纲可以另在“课程资料与题库”查阅。
3. 首页点「开始学习」会直接进入推荐知识点的诊断题；答错时显示缺失要点并提供补学，答对时进入迁移题。
4. 每道题包含三个独立要点，分别选择、分别计分。全错先补基础，部分正确补缺失环节，诊断题达标后做迁移题。
5. 补学内容显示本次缺失的要点和对应解释；阅读只算覆盖，不改变掌握度。
6. 首页自由提问只在索引含书名、章节、页码和可核对短段落时给教材要点；缺少教材时明确拒答。教学引擎仍可单独检索自编学习卡，不把学习卡标成教材页码。
7. 学习评估的结果页可提交具体疑问给研究判断闸门；记忆性疑问引回基础学习，符合条件的开放性问题再由用户主动进入文献漫游。英文检索式来自人工模板，不能保证逐句翻译。
8. PubMed 官方 E-utilities 实时检索，显示实际返回的标题、作者、期刊、年份、PMID、摘要、类型和链接。不预装或补造论文列表。
9. 阅读卡围绕原疑问显示真实摘要的简短结果摘录与核对提示；如摘要未标注结果则说明缺失，不自行推断结论。学生可返回同一知识点做迁移题。
10. 学习评估页展示实际要点评分、错误类别、首次与最近作答及可解释的掌握判断。个人中心支持下载学习摘要，以及分别清理学习记录或同时清理当前身份导入的索引。

### 主动学习计划与分步提示（2026-10-29）

首页“今天从这里开始”和右侧计划来自同一份真实记录：优先继续未完成题目，其次复习薄弱要点和到期任务，再推荐新知识。每天最多推荐2个新知识点，一次显示最多5项；“今日已练”统计上海时区内作答过的不同知识点。“到期待练”包含立即需复核的薄弱点与迁移任务，统计范围为整个脑神经示例章节。

诊断与迁移都有独立达标记录后，按独立迁移达标的学习日采用1／3／7／14天间隔。同一天重复高分不会推迟到期时间；提示辅助高分不增加独立达标天数，低分后重新巩固。该间隔是可解释的工程规则，尚未验证为记忆模型，也没有新增外部提醒或后台自动通知。

每个评分要点可主动展开两步思路提示：先分析题干条件，再整理结构、功能与表现之间的推理。当前提示是预设思考框架，不是开放式多轮导师。离开页面或刷新后可恢复同一任务与已用提示；只要使用过提示，本次整题标为“辅助练习”，不能用于建立独立掌握证据。结果、报告和学习记录导出会保留该标记。服务端记录提示使用情况，不能通过浏览器提交字段改成独立作答。

计划与提示均在本机运行，无模型API费用。课程大纲、OCR翻卡与书页问答尚未自动转换为已审定评分题，因此不混入该复习计划。

`tools/refine_histology_ocr.py --deps 本地依赖目录` 用于重识别（需要RapidOCR、Pillow、NumPy）；`tools/export_histology_review.py` 可导出带原图链接和疑点标记的 `data/course_materials/组胚复习资料_OCR优化稿_待校对.md`。原OCR备份、人工修字记录和导出稿均保留在被Git忽略的本机资料目录。

### 在页面中校对与整理

在“课程资料与题库”选择“组胚原图与知识检索”，可按尚未核对、优先核对、本机修订筛选文字。展开某行“编辑 / 核对”会定位原图，修改后可保存；只有主动勾选“已对照原图核对本行文字”才标记为本机已核对，继续改字会取消该勾选。修订立即用于本机资料检索，刷新后保留。

修订写入本机 `data/course_materials/histology.reviews.json`，保留每次保存及恢复记录；“恢复识别底稿”保留历史，不覆盖导入的原OCR。不同窗口修改同一行时，后保存者必须重新载入，不会静默覆盖；跨服务进程也会串行保存，避免覆盖整份历史。重新运行OCR导致原行变化时，也必须重新核对。页面中的独立表格整理稿保留首次转录，不随逐行修订自动改写。

未保存的逐行草稿保留在当前窗口内存中，切换筛选、翻页或保存其他行后仍可继续编辑；刷新或关闭前会提醒保存。遇到其他窗口修改，重新载入后保留草稿，并显示当前已保存文字供比较，需明确选择基于当前版本继续草稿。草稿尚未写入本机修订文件，关闭窗口后不能作为已保存资料找回。窄屏打开编辑器只定位图片内框，避免整页滚离输入框。

原图支持适应宽度及150%／200%／300%缩放，条目可按当前筛选结果的序号跳转。“导出当前筛选文字”下载当前匹配的全部条目，保留来源定位和待校对说明，不因文字片段筛选而丢失上下文。资料页面在桌面使用完整主区宽度。

这些校对记录属于本机共享的课程资料；个人中心清理匿名学习记录不会删除它们。核对标记只代表使用者对图检查，不等于教师审定，也不进入正式测评得分。

## 内容和能力边界

这是可运行、可扩展的原型，不是经过医学教师审核的正式教学平台。

- 当前只覆盖脑神经，不冒充完整的系统解剖学课程。
- 已提供的课程大纲保留在本机，尚未提供带可核对页码的教材正文或正式国家考纲。旧项目说明中的命中率与用户测试成绩不移植为本版本成绩。
- “掌握／熟悉／了解”是示例教学目标。界面明确注明待医学教师审核，没有把自编层级称为官方标准。
- 10 张自编学习卡参考公开资料编写；页面给出来源链接，但不标注虚构的人卫教材印刷页码。医学内容、试题和评分规则均需教师复核。
- 离线诊断采用结构化选择，补充自由文本推理只保存供人工复核，不冒称已实现可靠的开放式语义评分。
- 本地问答是基于字符二元词与英文词的加权覆盖率检索、摘录和拒答；不是旧项目的完整 BM25 / 向量混合 RAG。检索阈值是原型参数，尚未用独立医学数据集验证。
- 研究疑问识别采用保守规则。英文式是知识点级模板，不保证逐句翻译用户疑问，界面会明确提示。
- 文献类型来自元数据，不能直接视为证据质量分数。默认阅读框架不编造研究结论或全文信息。无摘要时明确显示缺失。
- 迁移题检验基础课程知识，不是针对每篇论文动态生成的理解测试。不会把完成迁移题当作掌握论文结论的证据。
- 不含导师匹配、模拟病人、账号登录或互联网多人部署。本地匿名学习身份用于区分记录，不是经过加固的多用户认证系统。
- 本地记录没有自动跨浏览器同步；导出用于归档，当前未实现导入学习历史。教材索引可以独立导入。

## 评分与决策

每道题三个要点等权，答对 0／1／2／3 个分别约为 0／33／67／100 分。首次掌握度取首次原始得分，此后：

```text
EMA = 0.4 × 旧掌握度 + 0.6 × 本次原始得分
```

标记“已掌握”同时要求：两个不同题目的最新作答均为独立作答且至少 80%，包含迁移题；最近两次均为独立作答且至少 80%；EMA 至少 80%。辅助练习仍记录原始得分和EMA，但不能满足独立达标条件。因此重复同一道题、只读学习卡、提示后的满分或单次满分都不足以标记掌握。之后出现错误或辅助作答可能降低当前状态。此判断为可解释的工程规则，尚未验证为有效的认知测量模型。

“首次／最近”可能是不同难度、不同情境的题目，仅是过程记录，不是教学效果实验或因果证据。报告不会将自测过程包装为真实用户试验。

## 接入大模型（可选）

“围绕本题继续讨论”另有免费Ollama连接器，传递真实多轮历史，并将作答前的对话计为辅助练习。与下述可选云模型配置独立，不自动使用已有API密钥。详见[免费本机多轮辅导](../docs/免费本机多轮辅导.md)。原两步提示仍作为快捷入口保留；多轮生成需本机已安装模型，未安装时仅提供明确标注的材料检索回应。

默认不调用模型，不产生模型 API 费用。支持服务端配置兼容的 Chat Completions 服务。以下是 PowerShell 示例：

```powershell
$env:MEDNEXUS_API_KEY = '填入你自己的密钥'
$env:MEDNEXUS_BASE_URL = 'https://api.deepseek.com/v1'
$env:MEDNEXUS_MODEL = 'deepseek-chat'
python server.py --open
```

请以服务商当前文档、账户权限和价格为准。不要把真实密钥写进代码或提交仓库。程序只从进程环境变量读取密钥，不返回给网页；`BASE_URL` 应为 API 根路径，程序追加 `/chat/completions`。

启用模型后，提问文本、命中的资料片段或所选论文的公开摘要会发送给所配置的模型服务。对本地私有教材有顾虑时保持默认离线模式。PubMed 检索只向 NCBI 发送英文查询式。

模型输出必须包含给定来源 ID 和连续摘录，系统会检查来源、书名、索引页码和摘录一致性；失败则回退本地抽取。该检查不证明解释在语义上完全受原文支持，界面将生成解释标注为需要核对。

本次没有使用用户密钥，因此实际付费模型调用未验证；已验证默认本地学习路径和模型失败回退的规则测试。

## 导入教材页码索引

在“知识库 → 导入本地教材索引”中选 JSON 数组或 JSONL 文件，确认使用权与隐私要求后导入。也可下载空白模板。模板的 `page` 留空，必须由使用者对照正版教材填为正整数。

```json
{
  "book": "填写核对后的教材名称",
  "edition": "填写版本",
  "chapter": "填写章节和知识点",
  "page": 12,
  "keywords": ["用于检索的术语"],
  "text": "可选：你有权在本机使用的段落文本",
  "url": "https://example.org/optional-source"
}
```

上面页码 12 仅说明格式，不对应任何真实教材。`url` 可省略，提供时只接受 HTTPS。每批最多 1000 条、JSON 请求不超过 2 MB；单条原文短段落最多 2000 字。整批先验证再写入；重复内容按哈希去重。

只存元数据时可以给出书名、章节与页码定位，但不能校验教材原文或基于原文作答。要做原文检索需自愿提供授权文本；这些内容保存在本机，导出团队包时不包含数据库。导入页码一律标注“待人工核验”，索引一致性校验不会冒充对正版原书的核验。

`reference-review/` 是读取 Word 内嵌图片时生成的本地辅助文件，不属于程序运行依赖，也不放入团队分发包。

## 测试

```powershell
python -m unittest discover -s tests -v
node --test tests/*.test.mjs
```

测试使用独立临时 SQLite，不写入实际学习数据库。PubMed XML 解析测试使用明确的合成测试数据，不把它作为真实论文展示。联网测试与浏览器检查详见 `验证记录.md`。

Windows 上如果 Python 的证书信任链与系统不同，PubMed 请求可自动使用 Windows 原生 HTTPS 客户端完成证书验证。该兼容路径仅允许 NCBI 官方 E-utilities，URL 通过标准输入传递给固定脚本；不关闭证书验证、不修改系统证书库、不把用户查询当作脚本执行。该路径不用于发送模型密钥。
