# Medical_AI · 医枢 MedNexus

面向医学生的主动学习与科研探索智能体原型。围绕具体知识点完成“主动诊断 → 按要点评分 → 针对性补学 → 有条件的文献探索 → 迁移再测 → 学习报告”。

- [**队友运行指南**：从零跑起来](docs/队友运行指南.md)
- [本机 / 内网运行与测试说明](docs/演示链接与测试情况.md)
- [部署到 Google Cloud Run（可选，非必需）](docs/Google-Cloud-Run-部署.md)

> 本项目**不依赖任何外部托管服务**：无需 ChatGPT、OpenAI 或云平台账号即可完整运行。
> **克隆下来就能跑**：只需 Python 3.10+，不装任何第三方包。仓库不含教材索引，因此默认没有页码引用；需要页码时按 [队友运行指南](docs/队友运行指南.md) 第五节生成。

当前覆盖系统解剖学“脑神经”的10个知识点与20道三要点题。总览、课程、章节和报告可实际使用，初始成绩为空，状态根据真实作答更新。

首页学习计划根据本机作答记录，优先安排未完成任务、薄弱要点和到期复习，每天最多推荐2个新知识点。独立迁移达标后使用1／3／7／14天工程间隔；作答可按需展开两步思路提示，使用提示会标为辅助练习，不能建立独立掌握证据。计划和提示不调用付费模型，当前仅覆盖上述脑神经示例章节。

本机可另行导入你提供的《系统解剖学》考点速记扫描件。导入后，“速记自测”显示 995 条翻卡考点，可按章节、编号和术语筛选，并打开 PDF 原页核对。该扫描件没有现成的选择题选项与答案，OCR 文字尚未逐条审核，因此翻卡只作自我复习，不进入现有三要点评分或掌握度统计。PDF 和 OCR 数据保留在本机 `mednexus/data/`，不提交到 GitHub。

## 本地启动

新增“围绕本题继续讨论”：支持自由文本多轮交流、历史恢复和引用检查。接入免费本机Ollama后使用真实会话上下文生成辅导；未安装模型时明确回退为材料检索。安装与验证边界见[免费本机多轮辅导](docs/免费本机多轮辅导.md)。最新回归为98项Python测试、23项前端流程测试通过；真实本机模型推理尚待模型安装后验证。

需要 Python 3.10+，不需要安装第三方 Python 包。

```bash
git clone https://github.com/hys-ai/Medical_AI.git
cd Medical_AI
python mednexus/server.py --open
```

Windows 也可双击仓库根目录的 `开始使用医枢.bat`。默认地址为 `http://127.0.0.1:7860`；关闭服务时在启动终端按 Ctrl+C。端口占用可改用 `python mednexus/server.py 7861 --open`。

本地版使用SQLite保存匿名学习记录与用户自行导入的资料，默认使用可解释规则与本地证据检索。可通过环境变量选配兼容的模型服务，详见 [本地版说明](mednexus/README.md)。不要将真实密钥写入源码或提交Git。

## 在线演示源码

`online-demo/dist/` 是可直接托管的静态源码，不是应忽略的构建缓存。它将学习记录保存在访问者浏览器的localStorage，不共享本地SQLite；PubMed英文查询直接发送到NCBI。

预览需要Python，仅启动静态文件服务：

```bash
python -m http.server 7871 --bind 127.0.0.1 --directory online-demo/dist
```

然后打开 `http://127.0.0.1:7871`。在线演示不连接付费模型；题目与答案随前端分发，适合自主学习和演示，不适用于保密考试。Sites账户绑定信息未包含在仓库，部署时需使用自己的托管配置。

## 运行测试

Python本地版与浏览器演示引擎分别测试，Node.js用于运行后者：

```bash
python -m unittest discover -s mednexus/tests -v
```

当前本地版运行 `python -m unittest discover -s mednexus/tests -q`，177项通过；`node --test mednexus/tests/*.test.mjs` 的85项流程回归通过。我的学习页可按本机导入的22章、233条大纲要求核对学习目标；补学按服务器错点逐项查依据，报告可查看原题与逐要点反馈，并直接补学或复测。辅助答对仍标记待独立复核，其他题答对不会清除旧题错点。刷新可恢复未提交选项、信心与推理草稿、上次反馈和当前窗口的文献草稿，不重复计分或自动检索。作答信心可自愿填写，推理记录不参与自动评分。研究疑问可取得透明的焦点词语建议，手动英文式优先；独立医学主题也可打开阅读卡，按原始摘要标签分栏，不推断未报告内容。本机已验证免费Qwen3 0.6B多轮生成通路，解释质量仍有限，完全重复的模型正文会回退本地材料。课程资料入口还支持55张组胚原图与207条待校对编号复习条目。完整测试范围与实际联网限制见 [验证记录](mednexus/验证记录.md)。`online-demo/` 是独立静态演示，本轮本地版改动尚未同步到该演示。工程测试不等于医学准确性或真实学习效果验证。

## 已合并：教材页级证据层

原「书页」项目已于 2026-10-24 并入本仓库，**不再作为独立目录存在**。合并方式是保留医枢的教学流程，替换它的证据层：

| 能力 | 合并前 | 合并后 |
|---|---|---|
| 补学依据 | 自编学习卡，无页码 | **本地教材索引，显示印刷页码** |
| 自由提问检索 | 字符二元组覆盖率，只看学习卡 | **BM25 + IDF 覆盖率，优先教材原文** |
| 拒答 | 覆盖率 0.33 | **覆盖率 0.30 + 至少命中 2 个查询词** |
| 引用校验 | 摘录字符串包含 | 同左，且页码只能来自索引记录 |

实现：`mednexus/textbook.py`，索引文件放仓库根目录 `chunks.jsonl` 或 `mednexus/data/chunks.jsonl`（**不入库**）。首页自由提问只在找到含书名、页码与原文的记录时显示教材要点；没有对应索引时明确说明缺少教材依据，不编造书页或总结。其他学习模块仍可使用自编学习卡。

首页示例「小胶质细胞的功能」采用两步流程：先显示教材书页与原文要点（若已导入），再询问是否进入文献漫游。只有用户点击按钮后才请求 PubMed；中文小胶质细胞主题映射到公开英文检索式，并按日期显示真实 PMID、标题和摘要。文献结果与教材依据分开展示，不把论文当作课本页码。当前仓库没有包含小胶质细胞的教材索引，因此该示例的教材部分会如实提示缺失；日后导入有授权的教材内容后即可显示对应书页。

生成索引（需要有教材 PDF，仅本机使用）：

```powershell
python tools/pdf_extract.py "教材.pdf" 100000 book_xxx.jsonl
python tools/build_chunks.py            # 产出 chunks.jsonl
```

## 当前验证边界

教学目标与医学内容仍需教师审核，正式大纲与教材页码仍需对照正版核验。阅读不直接算掌握，单题满分也不直接算掌握；首次和最近作答的变化仅为过程记录。工程测试通过不代表医学问答准确率、认知测量效度或真实学习效果已经验证。参赛素材、学习记录和第三方文献的使用边界见 [本地版说明](mednexus/README.md)。

教材页码来自本机索引，**索引本身需要人工核对**（三本书的 PDF 页与印刷页偏移分别为 +19 / +29 / +23），系统不会把索引页码标为“已核验原书”。

用于医学教育与科研入门，不提供个人诊疗建议。
