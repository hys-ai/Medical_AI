# 医枢 MedNexus 演示与测试情况

本项目**不依赖任何外部托管服务**，全部在本机或校园内网运行，不需要 ChatGPT、OpenAI 或任何云平台账号。

## 一、本机演示（最常用）

```powershell
开始使用医枢.bat
```

或

```powershell
cd mednexus
python server.py --open
```

默认地址 `http://127.0.0.1:7860`，只监听本机。

## 二、内网演示（同一 Wi-Fi / 教室局域网）

让同网段的同学直接访问你的电脑：

```powershell
cd mednexus
python server.py 7860 --host 0.0.0.0
```

启动后终端会提示 `LAN mode`。然后在**同一网络**的其他设备上打开：

```
http://<这台电脑的内网IP>:7860
```

查内网 IP：

```powershell
ipconfig | findstr IPv4
```

注意事项：

- 只允许内网地址（10.x / 172.16-31.x / 192.168.x）访问，公网 IP 会被同源校验拒绝
- 每台设备的浏览器会各自生成学习身份，记录互不干扰
- 如果 Windows 防火墙弹窗，选择「允许专用网络」
- 内网模式下不要暴露到公网；本项目没有账号体系

## 三、静态在线演示（可选）

`online-demo/dist/` 是一份纯静态页面，用任意静态服务器即可预览，同样不需要外网：

```powershell
python -m http.server 7871 --bind 127.0.0.1 --directory online-demo/dist
```

打开 `http://127.0.0.1:7871`。它将学习记录存在浏览器 localStorage；题目与答案随前端分发，适合自主学习和演示，不适用于保密考试。

## 四、实际测试结果

Python 本地版 35 项回归测试全部通过（`python -m unittest discover -s mednexus/tests -v`），浏览器演示引擎 28 项测试通过（`node online-demo/tests/engine.test.mjs`），合计 63 项通过、0 项失败。

浏览器已实际完成：进入章节主动出题；只答对一个要点得 33 分；按缺失环节补学；不同情境迁移题得 100 分；报告保存首次与最近成绩，EMA 约 73% 仍标为初步达标；刷新恢复记录；域外问题拒答；直接从 NCBI 检索真实文献、读取原始摘要，再返回原知识点迁移题。

390 像素手机布局已检查，无横向溢出。浏览器控制台未见错误或警告。

## 五、演示建议

用“动眼神经的功能与损伤”演示整条闭环。先只答对“上睑下垂”要点，观察针对性的反馈；补学后做迁移题，再以病因和瞳孔受累差异问题进入文献。最后打开报告核对实际作答记录。

## 六、使用边界

学习记录、推理与导入资料仅保存在本机 SQLite（内网演示时为各自浏览器对应的记录）；没有上传原始 Word 文档、截图附件或模型密钥。文献查询式直接发送到 NCBI。

浏览器演示版是规则驱动的教学演示，不连接付费大模型；Python 本地版保留 SQLite 与可选模型辅导能力。前端包含题库和答案，不能用作保密考试。工程测试通过不代表医学内容已审核、医学问答准确率已验证或真实学习效果已经证明。

当前仅覆盖脑神经 10 个知识点与 20 道题。正式教学大纲、教材页码、教师审核和真实学生试用仍待补齐。PubMed 可用性受访问者网络和接口限流影响，失败时会保留原站链接，不生成假论文。
