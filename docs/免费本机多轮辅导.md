# 免费本机多轮辅导

学习评估页的“围绕本题继续讨论”支持自由文本、连续追问、按题保存历史和断线重试。对话仅围绕当前脑神经示例题及自编学习卡，不自动给自由文本打分。作答前接受辅导会标记为辅助练习；提交后讨论不会回改原成绩。

生成辅导需要本机运行Ollama。没有模型或模型输出未通过来源检查时，页面明确使用“本地资料对话”，这只是材料检索回应，不是开放式生成教学。当前实现不连接收费云模型，不读取其他问答模块的API密钥。

## 启用生成模型

1. 从[Ollama官方Windows页面](https://docs.ollama.com/windows)安装，或下载官方便携包解压。
2. 在终端运行 `ollama pull qwen3:1.7b` 下载模型（约1.4GB，需要网络）。模型不是医学专用模型，回答仍需核对材料和教师审核。
3. 确保 `ollama serve` 正在本机11434端口运行，再启动医枢。

医枢默认检测 `http://127.0.0.1:11434`。可在启动医枢前设置 `MEDNEXUS_TUTOR_MODEL=qwen3:1.7b` 指定已下载的模型；未指定时优先选择本机已安装的Qwen3，否则选择第一个已安装模型。模型名称会显示在界面上。

便携运行可在同一个PowerShell窗口先设置：

```powershell
$env:OLLAMA_HOST = '127.0.0.1:11434'
$env:OLLAMA_MODELS = 'D:/AI智能体/.local-models/models'
$env:OLLAMA_NO_CLOUD = '1'
```

以上目录可按本机情况修改，不是项目运行的固定路径。只监听本机，不要将模型端口暴露到公网。运行时和模型无需提交Git。初次安装和模型下载需要联网，已下载模型的推理无云API费用，但会使用本机内存、CPU或GPU。

接口使用Ollama的[聊天API](https://docs.ollama.com/api/chat)和[结构化输出](https://docs.ollama.com/capabilities/structured-outputs)，传递完整的本题历史；响应中的来源ID与原句需匹配当前学习卡，失败则回退。引用匹配只证明出处一致，不能证明解释的医学正确性。

## 数据与验证边界

每题最多12轮。历史保存在本机SQLite并按学习身份与题目隔离。个人中心清理学习记录会同时删除教学对话；学习摘要导出不包含对话原文。请勿输入患者信息或个人资料。
