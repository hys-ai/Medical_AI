# 队友运行指南

> 目标：在自己的电脑上把医枢跑起来，5 分钟。
> 结论先说：**从 GitHub 拉下来就能跑，不需要装任何第三方包**；只有“教材页码”需要你本机有教材才能有。

---

## 一、需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| Python | **3.10 或更新** | 唯一的前置条件，装的时候勾选 “Add python.exe to PATH” |
| 网络 | 可以没有 | 诊断、评分、报告全离线；只有 PubMed 检索需要联网 |
| 第三方包 | **一个都不用装** | 不用 pip、不用 Node、不用 Docker |
| 磁盘 | 约 5 MB | 仓库本身只有 0.44 MB |

---

## 二、拿到代码（三选一）

### 方式 A：下载 ZIP（最省事，不用装 git）

1. 打开 <https://github.com/hys-ai/Medical_AI>
2. 绿色按钮 `Code` → `Download ZIP`
3. 解压到任意目录，例如 `D:\Medical_AI`

### 方式 B：GitHub Desktop

`File → Clone repository → URL` 填 `https://github.com/hys-ai/Medical_AI.git`

### 方式 C：命令行

```powershell
git clone https://github.com/hys-ai/Medical_AI.git
```

---

## 三、启动

进入解压后的目录，**双击 `开始使用医枢.bat`**。

或者命令行：

```powershell
cd Medical_AI
python mednexus/server.py --open
```

浏览器会自动打开 `http://127.0.0.1:7860`。

> 端口被占用时：`python mednexus/server.py 7861 --open`

**不要**直接双击 `mednexus/web/index.html` —— 页面是空壳，数据来自本地服务。

## 四、拉下来就能用什么

仓库里**不含教材索引**（`chunks.jsonl` 被 `.gitignore` 排除，因为涉及教材版权）。所以：

| 功能 | 没有索引时 | 有索引时 |
|---|---|---|
| 学习总览 / 我的课程 | ✅ 正常 | ✅ |
| 学习评估（出题、三要点评分、掌握度） | ✅ 正常 | ✅ |
| 学习报告、导出 JSON | ✅ 正常 | ✅ |
| 自由提问 | ✅ 能答，但**引用是自编学习卡，没有页码** | ✅ 引用教材原文并显示**印刷页码** |
| 科研探索 / PubMed | ✅ 正常 | ✅ |
| 知识库页 | 显示 0 本（空） | 显示 3 本、页码范围 |

想验证：提问「动眼神经损伤为什么上睑下垂」

- 没有索引：返回一段自编学习卡摘要，标注“自编学习卡”
- 有索引：返回《局部解剖学（第10版）》P25 的原文摘录

## 五、想要教材页码：两条路

> **只放 PDF 是不够的。** 程序读的是 `chunks.jsonl`（段落索引），不直接读 PDF。
> PDF 必须经过下面的“抽取 → 建索引”两步，才会变成 `chunks.jsonl`。

### 路线 A（最省事）：直接拿 `chunks.jsonl`

找队友要一个已经生成好的 `chunks.jsonl`（约 4.2 MB），放到**仓库根目录**（和 `README.md` 同级），启动服务即可。

- 不需要 PDF，不需要跑任何命令
- 这是教材正文索引，只在团队内部传，别公开

### 路线 B：自己从 PDF 生成

前提：你本机有这三本人卫教材的 PDF（团队成员自购，仅本机使用，不要上传）。

1. 把三本 PDF 放在**仓库根目录**（文件名随意，下面命令里对得上就行）：

```
07. 局部解剖学（第10版）.pdf
09. 生物化学与分子生物学（第10版）n.pdf
10. 生理学（第10版）.pdf
```

2. 抽取逐页文本（每本约 30 秒，**输出文件名必须照抄**）：

```powershell
python tools/pdf_extract.py "07. 局部解剖学（第10版）.pdf" 100000 book_jiepou.jsonl
python tools/pdf_extract.py "09. 生物化学与分子生物学（第10版）n.pdf" 100000 book_shenghua.jsonl
python tools/pdf_extract.py "10. 生理学（第10版）.pdf" 100000 book_shengli.jsonl
```

3. 生成段落索引：

```powershell
python tools/build_chunks.py
```

看到 `已生成 chunks.jsonl：5667 块` 就成功了。重启服务，提问就会带页码。

**为什么输出名必须照抄**：`tools/build_chunks.py` 里写死了这三个文件名和对应的页码偏移（解剖 +19、生化 +29、生理 +23）。命名不对会提示“跳过（文件不存在）”。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 双击 bat 一闪而过 | 没装 Python 或没加 PATH | 装 Python 时勾 “Add to PATH”；或命令行跑 `python mednexus/server.py` 看报错 |
| 页面白屏 | 直接开了 `web/index.html` | 必须访问 `http://127.0.0.1:7860` |
| 端口被占用 | 7860 已有人用 | `python mednexus/server.py 7861 --open` |
| 提问没有页码 | 没有 `chunks.jsonl` | 见第五节，或向队友要索引文件 |
| 知识库显示 0 本 | 同上 | 同上 |
| PubMed 搜不到 | 网络受限或 NCBI 限流 | 系统不会编造文献，会提示失败原因 |

## 七、要给别人演示（内网访问）

默认只监听本机。想让同一 Wi-Fi 的同学打开：

```powershell
python mednexus/server.py 7860 --host 0.0.0.0
```

1. 先双击 **`开放内网访问.bat`**，UAC 点「是」，放行 7860 入站（Windows 防火墙默认拦公用网络）
2. 查自己的内网 IP：`ipconfig | findstr IPv4`
3. 把 `http://<你的内网IP>:7860` 发给同学

如果对方还是打不开，大概率是校园网的 **AP 隔离**（禁止设备互访），改用手机热点，或都用 Radmin VPN 组一个虚拟局域网。
